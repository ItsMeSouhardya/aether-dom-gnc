# Task 04 — Editable 2.5D Stage Implementation Plan

> **For agentic workers:** Use test-first implementation. Fixed interfaces below allow independent contract/backend, SVG-security, and rendering-engine workers. Root owns studio integration, fixtures, browser acceptance and handoff. Leave all changes uncommitted for the user.

**Goal:** Move/reorder one visual layer without changing others, import/edit SVG sources without losing IDs, control the camera, and save/reload interpolated keyframes.

**Architecture:** One Three.js WebGL2 compositor with a native SVG overlay/fallback. SQLite/typed commands remain canonical; pointer drafts and preview time remain UI state. A lossless document 0.2 extension adds optional animation/asset metadata; the first accepted new stage command upgrades the document, and undo restores the prior authored version/state. Sanitized SVGs are immutable content-addressed local files, referenced by stable asset IDs.

**Stack:** Existing Next/React/TS/FastAPI/SQLite stack; pinned three and @types/three 0.187.0. No Pixi or second graphics framework. Official renderer/texture references: https://threejs.org/docs/pages/WebGLRenderer.html and https://threejs.org/docs/pages/TextureLoader.html.

**Spec:** Kit CODEX_TASKS Task04, master plan sections3–4/6/11.3, kit AGENTS, PRODUCT, selected design and docs/design/studio.md.

## Constraints and decisions

- Preserve original 0.1 schema/fixture, kit, landing, archives and sources. Keep existing documents/histories readable; do not silently migrate at startup. Keep user database intact during verification.
- Work from merged Task03 c56eec4 in feat/task-04-2-5d-stage, reusing current checkout. No commits/pushes/PR/merge.
- WebGL2 is the initial renderer backend for deterministic local support; native SVG remains usable when context creation/loss prevents GPU rendering. WebGPU is deferred; one Three compositor fulfills this slice.
- Camera faces negative Z without yaw/pitch: X/Y pan, Z dolly, FOV zoom. 100 SVG viewBox units =1 world unit. Aspect uses authored camera preset; UI exposes reset to16:9. No authored transform clamping.
- Depth is canonical transform.z. Bring forward/send backward chooses a new Z around the adjacent depth; only that layer changes. Preserve stable layer/asset/element IDs.
- Pointer drag uses camera-correct projection, ephemeral draft and captured base revision; release submits one transform command, Escape/cancel sends none. Busy/stale/unknown outcomes cannot silently rebase or overwrite. Keyboard/numeric controls remain available for obscured/offscreen layers.
- Layout mode edits base transforms. Animation mode previews keyframes; dragging is disabled there. Playback uses one RAF-driven UI clock, pauses on document/shot changes and never writes frames into canon. Interpolate all five transform numbers linearly; use base at t0 when no authored t0 frame, hold after the last frame.
- SVG edit mode isolates the selected prop in a native overlay. Select source IDs and edit supported geometry/presentation attributes through explicit Save; original source and asset ID remain stable. Changes to shared asset instances are disclosed.
- Import supports static SVG shapes/groups/text, bounded UTF-8 input256KiB, max512 nodes/depth16 and bounded attribute data. Reject scripts/events/foreignObject/DTD/entities/external refs/styles/filters/animations/unsupported elements, duplicate IDs, unsafe numbers or paths. Never silently strip unsafe content. IDs present in accepted source are preserved; missing IDs receive deterministic unused IDs.
- Only server-generated content hashes choose file paths. Reject redirected asset roots/children and escaped links. Preserve safe original bytes under assets/originals and normalized versions under assets/imported. No arbitrary file reads/network fetches. These local user directories are ignored by Git. Immutable unreferenced blobs can remain after a DB rollback; they are not exposed without a canonical asset reference.
- Add four original editable SVG fixtures at the existing visual asset URIs. Do not fabricate missing audio files; Task05 owns audio.

## Ownership and fixed interfaces

### Worker A — contracts and backend

Own packages/schema/**, apps/api/app/{contracts.py,commands.py,repository.py,main.py,dependency_graph.py,linter.py}, new stage-domain helper(s), corresponding API/schema tests and API/schema README. Do not edit SVG worker files, web components or root docs.

- Preserve cdom.schema.json/cdom.generated.ts for0.1. Add cdom.v0.2.schema.json and cdom-v2.generated.ts (CdomDocumentV2). New optional fields: layer.name:string, layer.visible:boolean, layer.opacity:number[0,1], layer.keyframes:[{id,timeMs,transform(full x/y/z/scale/rotationDeg)}]; asset.name:string and asset.sourceUri:string. At most128 keyframes/layer; unique IDs/times enforced by domain.
- Public CdomDocument is the V2 shape with schemaVersion '0.1.0'|'0.2.0', permitting optional extension fields at the type level; validators select the exact schema and reject V2 fields in V1 documents. validateCdom supports both and portable Unicode. Pure upgrade preserves all old fields and originals. No SQL migration.
- Command identifier0.3.0 retains all prior ops. New ops:
  - setShotCamera target shot, args{camera:{aspectRatio:'16:9'|'9:16'|'1:1',position:{x,y,z},fovDeg}}; finite XY within±1000,Z0.1..1000,FOV1..120.
  - setLayerAppearance target layer, args nonempty partial{visible:boolean,opacity:0..1}.
  - importSvgLayer target shot, args{assetId,layerId,name,rights:'project_original'|'licensed'|'unknown',svg:string}. IDs globally unused. New svg_plane at0/0/0 with scale=min(1,200/max(viewBox.width,viewBox.height)), rotation0. Name max80. Store only URIs/metadata in canon, not SVG bytes.
  - editSvgElement target asset, args{elementId,attributes:Record<string,string>}; only supported editable geometry/presentation attrs, never source IDs/viewBox/hrefs.
  - setLayerKeyframe target layer, args{keyframeId,timeMs,transform(full)}; time integer within shot duration, ID unique or same layer upsert, time unique, max128.
  - deleteLayerKeyframe target layer,args{keyframeId}.
- Every new op losslessly upgrades to0.2; exact undo restores field presence and schema version. Trusted internal restore-snapshot inverses are acceptable for this slice; never expose generic restore as a public command. Keep legacy inverse decoding. Every accepted action advances revision; old/removed IDs remain in receipts as appropriate.
- Include nested keyframes in global entity identity, dependency graph (keyframe→layer) and client analysis node coverage. Recompute same-revision analysis; preserve prior impact semantics and all Task03 rules.
- create_app(database_path=None,asset_root:Path|None=None) and Repository accept isolated asset roots. Default asset root is workspace, overridable by AETHER_ASSET_ROOT (workspace-like root containing assets/). Legacy tests with no SVG writes may retain default; all import/edit tests inject temp roots.
- GET /api/v1/projects/{projectId}/branches/{branchId}/assets/{assetId}?revision=N resolves only that referenced SVG asset at the requested immutable revision (current head if omitted). Return SvgAsset below, no-store; missing revisions/assets404, unsafe content422. No catch-all file serving.
- Health advertises latest schemaVersion0.2.0 and supportedSchemaVersions0.1.0/0.2.0; immutable fixture remains0.1.0.
- Shared svg.schema.json, generated types, validateSvgAsset(value) ->{valid:true,asset}|{valid:false,issues}. Public SvgNode/SvgAsset types exactly:
```
SvgNode={tag:'svg'|'g'|'path'|'rect'|'circle'|'ellipse'|'line'|'polyline'|'polygon'|'text',id:string,attributes:Record<string,string>,text:string,children:SvgNode[]}
SvgData={viewBox:{x:number,y:number,width:number,height:number},root:SvgNode}
SvgAsset=SvgData & {assetId:string,uri:string,sourceUri:string}
```
Client validator enforces allowed tags/attributes, bounded tree/text and finite positive viewBox; no arbitrary React properties or raw HTML.

### Worker B — SVG assets/security

Own only apps/api/app/svg_assets.py (helpers if needed) and new tests/test_svg_assets.py. No schema/main/commands changes. Use Python stdlib XML with strict UTF-8/DTD/entity rejection and allowlist. Coordinate with WorkerA.

- parse_svg(text:str)->SvgData. Normalize/preserve IDs, supported attributes and viewBox. Edits allow geometry/presentation attrs applicable to the selected tag; reject unsupported/unsafe values. Static text is text, never markup.
- SvgAssetStore(root:Path): import_svg(text)->{uri,sourceUri,svg:SvgData}; read_svg(uri)->SvgData; edit_svg(uri,element_id,attributes)->{uri,svg:SvgData}. Immutable safe originals/normalized versions stored as above; edit never alters original. New paths derived only from SHA-256. Validate existing version integrity and containment before reading/writing. Bounded file reads. No DB coupling.
- Need no new dependency if strict parser is sufficient; consult official docs if choosing one. Throw typed errors; do not echo unpaired/unsafe payloads into responses.

### Worker C — rendering engine

Own only apps/web/src/features/stage/**, components/stage/{gpu-stage.tsx,svg-content.tsx} and new engine tests. Root owns existing LayerStage/Timeline/inspector/shell and asset loader. Types from shared schema arrive through WorkerA.

- interpolateTransform(layer,timeMs)->Transform. Pure, non-mutating, sorted keyframes, base at0 unless explicit0, linear values, hold after last.
- projectLayer(transform,camera,viewport:{width,height},viewBox)->{x,y,width,height,rotation,pixelsPerWorld}|null. Camera axis fixed−Z. Positive authored rotation projects clockwise negative SVG degrees. Reject near/behind/nonfinite projection. unprojectDelta(dx,dy,z,camera,viewport)->{x,y}|null uses same camera. World units above.
- nextLayerDepth(layers,layerId,direction:'forward'|'backward')->number|null; stable Z ordering and ties, move only target beyond adjacent slot. Bounds/finite arithmetic handled.
- createPlayback(durationMs, optionalClock)->Playback. getSnapshot()=>{timeMs,playing}; subscribe(listener)=>unsubscribe; seek(ms),play(),pause(),dispose(). One bounded RAF clock; clamp duration; stop on end; cancel on dispose. Inject clock for meaningful tests.
- SvgContent({node,scopeId,selectedId?,onSelect?}) renders whitelisted React SVG tree, escaping text and scoping DOM IDs while retaining data-element-id source IDs. onSelect called with source ID (stop pointer propagation). svgMarkup(asset:SvgAsset)->string for texture from the same safe tree, never untrusted raw HTML.
- GpuStage({width,height,camera,layers:[{id,transform,keyframes?,visible?,opacity?,svg:SvgAsset|null}],playback,animate,hiddenLayerId?,onMode:(mode:'webgl2'|'svg')=>void}) renders absolute canvas. Use direct WebGL2 context preflight, Three.js scene/camera/textured planes, proper alpha/depth order, renderer resize, loss fallback and complete texture/material/geometry/RAF/objectURL disposal. No console errors on expected GPU absence. No canon writes, network requests or UI controls here. Native SVG fallback is root's overlay. Subscribe to shared playback; no global React frame store.
