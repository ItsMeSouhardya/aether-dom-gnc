Mode: **Operate**. This extends the selected Afterlight identity into the product; the landing design remains independent.

Only a successful validated server response updates the stage and saved outputs. Selection/drafts are temporary; SQLite snapshots are canon.

A visible border, focused bounds and named navigator identify selection. The navigator and numeric inspector remain reliable for hidden/obscured/off-frame layers.

Native fallback preserves edit access. Imported scripts, active/unsupported content and unsafe references are rejected with explicit errors.
