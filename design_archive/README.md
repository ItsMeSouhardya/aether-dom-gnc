# Frozen landing design references

Created 11 November 2026 when the user selected Afterlight v2 as the main design.

- afterlight-v1/: original cinematic Afterlight, with self-contained HTML, CSS, interactions, artwork and fonts.
- signal/: original industrial Signal, with self-contained HTML, CSS, interactions, artwork and fonts.

These are reference snapshots. Keep this entire folder untouched unless the user explicitly requests archive changes. Future main-page edits belong in landing-page/. The snapshots omit comparison controls and are not included in the main build. Their assets are copies, not shared with the main page.

From the project root, run `npm run archive:afterlight` (http://localhost:4181) or `npm run archive:signal` (http://localhost:4182). No installation is required. Stop a reference server with Ctrl+C.

DESIGN-AT-SELECTION.md and ASSET-SOURCES.md are historical source records. archive-manifest.json records the snapshot hashes.
