IDs nonempty safe route IDs `[A-Za-z0-9][A-Za-z0-9_-]{0,127}`; new ID globally unused within the copied document/project branches. New edits/undo operate independently and increment the child's revision fromN.
- Store immutable fork audit/lineage with source branch/revision, new branch, command payload/actor/reason/date. Names may duplicate; dropdowns include IDs.
- API GET `/api/v1/projects/{p}/branches`; POST same with ForkBranchCommand. API GET `/api/v1/projects/{p}/diff?left=<branch>&right=<branch>` captures both current heads/lineage under one read transaction. No arbitrary base or file path.

Walk each branch ancestry with maximum available revision at each ancestor; select nearest common ancestor branch and minimum of its two revision bounds. Read that exact immutable snapshot.
